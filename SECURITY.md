# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, prompt injection vector, or safety circumvention in `master-skill`:

1. Do NOT open a public GitHub issue.
2. Please open a private security advisory on GitHub or email the maintainers directly.
3. Include details of the prompt, the agent environment, and the unexpected behavior.

We take security seriously and will acknowledge reports within 48 hours.
