# 🛡️ AgentShield: Autonomous AI Firewall & Mesh Lock Engine

> **The definitive safety guardrail and decentralized lock arbitration system for autonomous AI agents.**

AgentShield intercepts dangerous commands, quarantines plaintext API keys, and prevents multi-agent race conditions before code is written or executed.

### 🌟 Core Capabilities:
- 🚫 **Zero-Destruction Shell Wall:** Intercepts `rm -rf`, `DROP TABLE`, `git reset --hard`, and disk formatting commands before they reach your OS.
- 🔑 **12-Pattern Secret Scanner:** Scans and blocks plain-text leaks of AWS, OpenAI, GitHub PATs, Anthropic tokens, and Stripe credentials.
- 🔒 **Decentralized Multi-Agent Mesh Locks:** Allows multiple AI agents to collaborate on the same repository without colliding or overwriting each other's code.
- 📋 **Contract-Driven Stop Gates:** Enforces green test baselines and deterministic verification assertions.
- ⚡ **Zero External Dependencies:** Instant cold-start (<15ms) across Windows PowerShell, Linux, and macOS.

### 🧰 Native Tools:
1. `safety_validate_command` — Pre-flight audit for shell commands.
2. `safety_init_contract` — Declares path boundaries and stop gates.
3. `safety_verify_gate` — Runs deterministic tests before code changes.
4. `safety_mesh_lock` — Claims exclusive file-tree locks.
5. `safety_mesh_unlock` — Releases acquired locks.
6. `safety_mesh_status` — Inspects all active locks and expirations.
7. `safety_scorecard` — Live audit of allowed vs quarantined actions.
